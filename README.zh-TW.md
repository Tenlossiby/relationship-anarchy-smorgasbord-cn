## 📖 這是什麼

關係安那其拼盤（Relationship Anarchy Smörgåsbord）是一套用來探索、描述與討論關係的工具。你和對方可以從不同「菜單」中挑選任意數量的「菜色」：可以很多，也可以只選一點點。這些由你們自行理解、討論和調整的菜色，慢慢組成屬於你們的關係。

它不會替任何關係套上標準答案，也不會用分數判斷兩個人是否適合。卡牌只是對話的入口，真正重要的是每個人如何理解問題、說出自己的期待，並尊重彼此的界線。

### 💡 核心理念

- **互動與溝通**：工具不能取代真實對話，而是協助大家找到比較容易開口的位置。
- **共同定義**：同一個詞對不同人可能有不同意思，不必急著找到唯一正確的解釋。
- **不預設框架**：關係不需要符合伴侶制、排他性或其他既定模板。
- **保留差異**：討論不一定要得到共識；不確定、需要再談與明確拒絕都可以被好好記錄。
- **允許改變**：人的需求和關係都會流動，拼盤也可以隨時重新調整。
- **多元包容**：適用於伴侶、朋友、酷兒柏拉圖式關係、家人、室友、照護網絡，以及其他由參與者自行命名的關係。

## ✨ 功能特色

### 🎯 探索與記錄

- **28 個關係類別、179 張卡牌**：涵蓋日常生活、情感支持、身體親密、性、權力、照護、財務、科技與未來安排等主題。
- **七種可複選標記**：同意、必要、也許、未來可能、需要討論、絕對不行、硬性界線。
- **行動者補充**：需要時可以記錄由誰參與，不會改變原本標記的意義。
- **多檔案管理**：可以為不同關係建立各自的檔案，並隨時繼續探索。

### 🤝 跨裝置非同步使用

- 每個人可以在自己的裝置上獨立思考與填寫。
- 完成後可匯出 TXT 檔案或分享口令，再透過自己信任的通訊方式交給對方。
- 收到的檔案可以匯入本機查看，也可以另建一份可編輯副本。
- 對照頁會呈現相近、不同、值得聊聊與尚未回答的地方，不產生契合度或關係結論。

### 🎨 使用體驗

- 支援簡體中文與繁體中文切換。
- 支援淺色、深色與跟隨系統三種外觀。
- 適用於手機、平板與桌面瀏覽器。
- 底部頁籤會保留各自最後查看的頁面、捲動位置與尚未完成的當次草稿。

### 🔐 隱私原則

- 個人回答預設只存在目前瀏覽器的本機儲存空間，不會自動上傳。
- 不需要註冊帳號，也不會收集個人資料。
- 匯出前可以選擇是否包含備註。
- Base64 只是編碼，不是加密；分享前請先確認檔案中是否有敏感內容。
- 清除瀏覽器資料可能同時刪除本機檔案，重要內容請自行匯出備份。

## 🚀 使用方式

### 線上使用

🌐 [https://relationship-anarchy-smorgasbord-cn.netlify.app/](https://relationship-anarchy-smorgasbord-cn.netlify.app/)

不需要安裝，直接用瀏覽器開啟即可使用。

### 1. 選擇想探索的類別

在「探索」頁挑選一個或多個類別，也可以隨機抽取三個類別。這不是測驗題目，不需要一次完成全部內容。

### 2. 建立關係檔案

第一次使用時，需要填寫：

1. 你的名字；
2. 對方的名字；
3. 關係標籤，或自行填寫其他稱呼；
4. 可選的檔案名稱。

一份檔案記錄的是某位填寫者對這段關係的回答。不同的人可以各自建立、填寫並交換自己的檔案。

### 3. 填寫卡牌

每張卡牌都有一個主題、問題與可能的延伸提問。閱讀後可以複選下列標記：

| 標記 | 可以怎麼理解 |
|------|--------------|
| ✅ 同意 | 對這項描述或期待感到同意 |
| 🔥 必要 | 對自己而言是重要且必要的 |
| 💭 也許 | 有興趣、不確定，或需要更多脈絡 |
| 🔮 未來可能 | 現在不適合，但未來可能願意考慮 |
| ❓ 需要討論 | 希望和對方進一步談清楚 |
| ❌ 絕對不行 | 明確不接受 |
| 🚫 硬性界線 | 不可跨越、需要被尊重的界線 |

這些標記不一定能直接回答每一個問題，這是正常的。你也可以跳過、只寫備註，或稍後再回來。

### 4. 查看與備份檔案

檔案詳情會顯示探索進度和已填寫內容。你可以匯出 TXT 備份，或產生分享口令交給對方。

### 5. 匯入別人的檔案

在「檔案」頁選擇「匯入檔案」，貼上分享口令或上傳 TXT 檔。應用會先顯示預覽，確認後才寫入本機。

別人分享的檔案預設是只讀資料；如果想以它為起點繼續填寫，可以另建一份自己的副本。這樣不會把對方原本的回答改成自己的回答。

### 6. 對照並開始討論

在檔案列表勾選兩份或更多檔案，再開啟對照頁。你可以依類別查看彼此相近、不同、需要再談或尚未回答的內容。

對照結果不是配對分數，也不代表多數人的選擇就是共識。任何人的「絕對不行」與「硬性界線」都不應被平均或忽略。

### 7. 調整語言與外觀

在「關於」頁上方的精簡顯示列中，可以切換：

- 简体中文／繁體中文；
- 淺色／深色／跟隨系統。

## 🛠️ 技術與本機開發

主要技術：Next.js 16、React 19、TypeScript 5、Tailwind CSS 4、shadcn/ui 與 Lucide React。資料保存在瀏覽器 `localStorage`。

```bash
pnpm install
pnpm dev
```

提交變更前可執行：

```bash
pnpm typecheck
pnpm test
pnpm lint
pnpm build
```
