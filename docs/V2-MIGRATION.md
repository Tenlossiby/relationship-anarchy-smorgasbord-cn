# V2 数据与隐私说明

## 方向

每份档案都表达“作者 → 对象”。导出、导入、复制和比较都保留这个方向；如果另一位参与者要表达自己的观点，应新建相反方向的档案。名字只是显示名，不是身份主键。

## 导入

- V2 导出使用 `kind: ra-smorgasbord-profile` 与 `schemaVersion: 2`。
- 导入前会校验机读区、字段、日期、回答数量、文本大小和摘要；失败不会写入半成品。
- 导入档案是只读快照，保留来源档案 ID、导出 ID 和导入时间。
- “创建可编辑副本”会保留来源标记，并明确它已不再是原件。
- V1 Next.js 档案原样迁移 `fromName → toName`；矛盾旧状态保留原始状态并标记人工复核。
- 只有 `partnerName` 等信息的旧 Expo 档案不能猜测方向，必须由用户确认作者和对象后再导入。

## 回答与比较

V2 将回答拆为单选 `stance`、多选 `markers`、可选 `participation` 和备注。只写非空备注也是有效回答；完全空白的回答会被删除，不计进度。比较页只显示“相近”“有所不同”“值得聊聊”“有人未回答”和备注提示，不计算匹配度，也不替用户判断关系结果。

## 隐私边界

数据默认只保存在浏览器本地；本地保存不等于设备加密。导出前可排除备注，导出摘要会显示方向、回答数和是否包含备注。Base64 只是编码，不提供加密或身份认证。应用核心流程不需要账号、云同步、API key 或第三方模型。
